# Эмулятор командной оболочки ОС (Вариант 20)

## Описание
Проект представляет собой эмулятор командной строки UNIX-подобной ОС 
с графическим интерфейсом на базе библиотеки Tkinter.

## Настройки и ключи запуска
- `--vfs` — путь к XML-файлу с виртуальной файловой системой.
- `--script` — путь к стартовому текстовому файлу команд.

## Сборка и запуск тестов
Запуск юнит-тестов:
```bash
python3 -m unittest discover -s tests
